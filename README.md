# تل‌چت (Telchat)

پیام‌رسان شخصی شبیه بخش گفتگوی تلگرام، قابل نصب روی هاست **cPanel** با PHP و MySQL.
روی **اندروید** و **iOS** به‌صورت برنامه نصب می‌شود (PWA) و برای اندروید یک **اپ بومی (APK)** هم دارد که اعلان‌ها را بدون هیچ سرویس خارجی دریافت می‌کند.

> **بدون وابستگی به اینترنت بین‌الملل:** هیچ CDN، فونت گوگل، Firebase یا سرویس خارجی استفاده نشده است. اگر هاست شما داخل ایران باشد، برنامه در زمان قطعی اینترنت بین‌الملل هم کار می‌کند.

## امکانات

**گفتگو**
- گفتگوی خصوصی، گروه، و «پیام‌های ذخیره شده»
- ارسال متن، عکس (با فشرده‌سازی خودکار)، ویدیو، فایل، موزیک و **پیام صوتی**
- پاسخ (Reply)، ویرایش، حذف برای خود یا همه، بازارسال (Forward)، کپی
- واکنش با ایموجی (Reactions)، سنجاق کردن پیام در گفتگو
- تیک‌های ارسال/خوانده شدن (✓ و ✓✓)، «در حال نوشتن...»، «در حال ضبط صدا...»
- وضعیت آنلاین و آخرین بازدید
- جستجوی گفتگوها، کاربران و پیام‌ها؛ جستجو داخل هر گفتگو
- تعداد پیام‌های خوانده نشده، سنجاق و بی‌صدا کردن گفتگو
- کشیدن پیام برای پاسخ (موبایل)، نگه داشتن انگشت برای منو، دوبار کلیک برای واکنش
- پیش‌نویس خودکار، ایموجی، کشیدن و رها کردن فایل، چسباندن عکس
- گروه: سازنده/مدیر/عضو، افزودن و حذف عضو، ویرایش نام/توضیحات/عکس گروه، رسانه‌های گروه

**تنظیمات (مثل تلگرام)**
- ویرایش پروفایل: عکس، نام، نام کاربری، بیوگرافی
- اعلان‌ها و صداها
- **حریم خصوصی و امنیت:**
  - چه کسانی آخرین بازدید و آنلاین بودن مرا ببینند (همه / مخاطبین من / هیچ‌کس)
  - چه کسانی عکس پروفایل و بیوگرافی مرا ببینند
  - چه کسانی مرا به گروه اضافه کنند
  - کاربران مسدود شده (Block)
  - قفل برنامه با رمز عددی و قفل خودکار
  - تغییر رمز عبور (با خروج از همه دستگاه‌های دیگر)
  - دستگاه‌های فعال و خروج از راه دور
  - حذف حساب کاربری
- تنظیمات گفتگو: حالت شب، اندازه متن، ارسال با Enter
- مخاطبین

## نصب روی cPanel

### ۱. نیازمندی‌ها
- PHP نسخه **8.0** یا بالاتر (افزونه‌های `pdo_mysql`، `openssl`، `curl`، `mbstring` و ترجیحاً `gd`)
- MySQL یا MariaDB (یا SQLite بدون نیاز به ساخت دیتابیس)
- **SSL (HTTPS)** — برای نصب روی گوشی و اعلان‌ها لازم است. در cPanel از بخش **SSL/TLS Status** گزینه **Run AutoSSL** را بزنید.

### ۲. آپلود فایل‌ها
1. از گیت‌هاب گزینه **Code → Download ZIP** را بزنید.
2. در cPanel وارد **File Manager** شوید و فایل ZIP را در `public_html` (یا یک ساب‌دامین مثل `chat.example.ir`) آپلود و **Extract** کنید.
3. مطمئن شوید فایل `index.html` مستقیماً داخل پوشه سایت است (نه داخل یک پوشه دیگر).
4. پوشه‌های `uploads` و `inc` باید قابل نوشتن باشند (معمولاً پیش‌فرض 755 کافی است).

### ۳. ساخت دیتابیس
در cPanel بخش **MySQL® Database Wizard**:
1. یک دیتابیس بسازید (مثلاً `cpuser_telchat`)
2. یک کاربر بسازید و رمز بدهید
3. **ALL PRIVILEGES** را به کاربر بدهید

### ۴. اجرای نصب‌کننده
آدرس `https://your-domain/install.php` را باز کنید، اطلاعات دیتابیس و حساب مدیر را وارد کنید و **نصب** را بزنید.
پس از نصب، **فایل `install.php` را حذف کنید.**

### ۵. تنظیمات اختیاری PHP
در cPanel بخش **MultiPHP INI Editor** برای ارسال فایل‌های بزرگ:
```
upload_max_filesize = 50M
post_max_size = 55M
max_execution_time = 60
```

تنظیمات برنامه بعد از نصب در فایل `inc/config.php` است:
| گزینه | توضیح |
|---|---|
| `allow_registration` | ثبت‌نام آزاد باشد یا نه |
| `register_code` | کد دعوت برای ثبت‌نام (اگر خالی نباشد) |
| `max_upload_mb` | حداکثر حجم فایل |
| `poll_timeout` | مدت انتظار هر درخواست زنده (ثانیه). روی هاست‌های اشتراکی با محدودیت پردازش، عدد کمتر (مثلاً 10) بگذارید |

## نصب روی گوشی

### اندروید — اپ بومی (پیشنهادی)
اپ اندروید یک سرویس پس‌زمینه دارد که **مستقیم به سرور شما وصل می‌شود** و بدون Google Play Services و Firebase اعلان نمایش می‌دهد؛ پس در زمان قطعی اینترنت بین‌الملل هم اعلان‌ها می‌رسند. امکانات آن:
- نمایش اعلان حتی وقتی برنامه بسته است
- پاسخ مستقیم از داخل اعلان و دکمه «خواندم»
- اجرای خودکار بعد از روشن شدن گوشی

**ساخت APK:** فایل APK با GitHub Actions ساخته می‌شود:
1. در گیت‌هاب به تب **Actions** و سپس **Build Android APK** بروید.
2. **Run workflow** را بزنید (می‌توانید آدرس سرور را هم وارد کنید تا در اپ ذخیره شود).
3. بعد از چند دقیقه، فایل `telchat.apk` در بخش **Releases** آماده است.
4. فایل را با نام `telchat.apk` در پوشه `download` روی هاست آپلود کنید. کاربران اندروید از داخل برنامه (تنظیمات ← نصب برنامه روی گوشی) آن را دانلود می‌کنند.

> این کار را وقتی اینترنت بین‌الملل وصل است یک بار انجام دهید و APK را روی سرور خود نگه دارید.

بعد از نصب اپ، در اولین اجرا آدرس سرور را وارد کنید. در صفحه بعد اجازه «عدم بهینه‌سازی باتری» را بدهید تا اندروید سرویس دریافت پیام را نبندد. در گوشی‌های شیائومی، هوآوی و سامسونگ بهتر است در تنظیمات گوشی «Autostart» را هم برای برنامه روشن کنید.

**کلید امضای اختصاصی (اختیاری):** برای امنیت بیشتر، یک keystore بسازید و در **Settings → Secrets and variables → Actions** این Secretها را تعریف کنید: `ANDROID_KEYSTORE_BASE64`، `ANDROID_KEYSTORE_PASSWORD`، `ANDROID_KEY_ALIAS` و `ANDROID_KEY_PASSWORD`. اگر تعریف نشوند، از کلید پیش‌فرض داخل پروژه استفاده می‌شود.

### اندروید — نصب از مرورگر (PWA)
سایت را در Chrome باز کنید و دکمه «نصب» یا منوی ⋮ و سپس **Install app** را بزنید.

### آیفون و آیپد (iOS 16.4 به بالا)
1. سایت را در **Safari** باز کنید.
2. دکمه **Share** و سپس **Add to Home Screen** را بزنید.
3. برنامه را از صفحه اصلی باز کنید و از **تنظیمات ← اعلان‌ها و صداها** اعلان‌ها را فعال کنید.

## اعلان‌ها و قطعی اینترنت بین‌الملل

| حالت | اینترنت عادی | قطعی اینترنت بین‌الملل |
|---|---|---|
| ارسال و دریافت پیام | ✅ | ✅ (فقط با هاست داخل ایران) |
| اعلان وقتی برنامه باز است (حتی در پس‌زمینه) | ✅ | ✅ |
| اعلان با برنامه بسته در **اپ اندروید** | ✅ | ✅ |
| اعلان با برنامه بسته در مرورگر یا PWA (Web Push) | ✅ | ❌ — به سرورهای گوگل/اپل وابسته است |
| اعلان با برنامه بسته در **آیفون** | ✅ | ❌ — اپل فقط از طریق سرورهای خودش اجازه می‌دهد |

Web Push فقط یک امکان اضافه برای زمانی است که اینترنت عادی است. اگر در دسترس نباشد، برنامه بدون مشکل کار می‌کند.

## ساختار پروژه
```
index.html, sw.js, manifest.webmanifest   برنامه وب (PWA)
assets/                                   CSS، JS، فونت وزیرمتن و آیکون‌ها (همه محلی)
api/index.php                             نقطه ورود API
inc/                                      کد سرور (دسترسی مستقیم مسدود است)
uploads/                                  فایل‌های ارسالی (اجرای اسکریپت مسدود است)
download/                                 محل قرار دادن telchat.apk
android/                                  سورس اپ اندروید
install.php                               نصب‌کننده (پس از نصب حذف شود)
```

## ارتباط زنده
برای سازگاری با هاست‌های اشتراکی cPanel که WebSocket ندارند، از **Long Polling** استفاده می‌شود: هر کاربر یک درخواست باز به سرور دارد و پیام‌ها بلافاصله تحویل داده می‌شوند.
